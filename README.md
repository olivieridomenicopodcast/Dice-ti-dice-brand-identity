# DICETIDICE — brand identity e Studio

Brand identity di DICETIDICE e **DICETIDICE Studio**, la web app (PWA) che crea caroselli, post e cover reel con colori, font e stile del brand.

## Cosa c'è
- **App:** `index.html` + `app/` — si usa dal telefono, si installa sulla schermata home e funziona anche offline.
- **Brand guide:** `brand-guide.html` — palette, font, logo, regole d'uso, tono di voce.
- **Template:** `app/layouts.js` (quelli usati dall'app) e `templates/carosello.html` (versione HTML di riferimento).
- **Istruzioni per Claude Code:** `CLAUDE.md`.

## Pubblicare l'app (GitHub Pages)
1. Su GitHub apri il repo → **Settings** → **Pages**.
2. In *Build and deployment* scegli **Deploy from a branch**, seleziona il branch che contiene l'app e la cartella **/ (root)**, poi **Save**.
3. Dopo circa un minuto l'app è online su `https://olivieridomenicopodcast.github.io/Dice-ti-dice-brand-identity/`.

## Installarla sul telefono
- **iPhone:** apri l'indirizzo in Safari → Condividi → *Aggiungi a Home*.
- **Android:** apri l'indirizzo in Chrome → menu ⋮ → *Installa app*.

## Come si usa
1. **Crea:** scegli il formato (carosello, post, quadrato, cover reel), aggiungi le slide, scrivi i testi e scegli le foto dalla galleria. L'anteprima si aggiorna subito.
2. **Scarica le immagini:** salva i PNG nella cartella Download del telefono (compaiono anche in Galleria). **Condividi** apre invece il menu del telefono (WhatsApp, Telegram…). C'è anche lo zip.
3. **Brief per Claude:** dalla stessa scheda ottieni il messaggio già ordinato da incollare in Claude Code, con l'opzione di far aggiungere le novità come nuovo template all'app.

Testi e foto restano solo sul tuo telefono.
